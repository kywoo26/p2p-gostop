# 전문 스킨 적용 준비 · design/pro-skin

> 2026-09-30 현행 적용 기준: [상용 레퍼런스 분석](commercial-reference-review.md). 카드 식별·정보 위계를 먼저 검토한다. 아래 이전 장식/배치 결정 중 충돌하는 내용은 이 분석과 최신 ui-spec이 대체한다.

상태: 2026-09-29 #104 병합(main `9f778f3`) 후 `design/pro-skin` 구현 시작. 1차는 판·HUD·홈 스킨(PA-05), 사건 효과·음향(PA-06)과 정산·설정·기록(PA-07)은 후속 PR이다. spec FR-40·FR-46~50·UX-11/13/18·NF-01/03/07, plan .1-A·PA-01~04. [아트 디렉션](art-direction.md)의 채택 방향을 구현하되 구조 정본은 **#104와 #159 병합 결과**이며 사용자 C/A 결정으로 각 진영 HUD와 같은 크기의 손패를 적용한다. 게임·입력 로직은 보존한다.

## 1. 시작 조건과 이식 경계

1. #104 리뷰 수정과 병합이 끝난 뒤 origin/main을 갱신하고 #104 병합 커밋을 포함하는지 확인한다. 그 main에서 `design/pro-skin`을 분기하고 기준 SHA를 PR 본문에 남긴다. 사람이 하는 병합을 대신 수행하지 않는다.
2. #147에서 출처·라이선스·결정성 검사·가공 스크립트와 필요한 원본만 선별한다. 평가용 Board/Screen 배치나 pro.css 전체를 합치지 않는다. 본선에는 실제 사용한 최적화 산출물만 포함한다.
3. 재질/조명 → 자체 패널·고/스톱·정산 → 초상 → 사건 장식 순으로 적용하고 각 단계에서 #104의 동일 fixture와 비교한다. 게임·P2P·정산 로직 및 anim/시간 토큰은 소유자 영역을 유지한다.
4. 1.5 MiB를 넘으면 해상도·포맷·중복 자산을 줄이거나 비필수 장식을 제외한다. 현행 예산은 전체 dist 기준이므로 lazy loading만으로 초과를 통과시키지 않는다. 세션/Android 팩 상한 개정은 별도 리뷰·승인 전 적용하지 않는다.
