# 상용 맞고 레퍼런스 분석과 적용 기준

2026-09-30 · PR #171 · spec FR-12/14/40/46~50, NF-08 · ui-spec UX-06/11/H05

**목표는 판을 보는 즉시 내 패, 먹은 패, 점수, 돈, 사건 상태를 읽는 것이다.** 사용자가 이 레퍼런스를 제시한 이유를 장식 취향이나 격자 선택으로 축소하지 않는다. 이 문서는 구현 변경에 앞서 참고 화면의 장점과 적용 이유를 고정한다.

자료: 사용자가 제공한 상용 앱 정지 캡처 `.visual-source/reference-commercial-board.jpg`. 외부 앱의 이미지·폰트·코드·아이콘은 저장소에 복사하지 않는다. 아래 관찰은 그 캡처에 근거하며, 공개되지 않은 다른 화면이나 동작을 관찰했다고 주장하지 않는다.

## 1. 사용자가 선호한 이유

사용자 설명은 “심플하면서 모든 게 표현됨”, “패 배치·획득 내역·똥/흔들·점수/돈이 한눈에 보임”이다. 따라서 좋은 화면의 판정 기준은 구성요소 수나 장식의 완성도가 아니라 **플레이 중 필요한 정보를 찾는 수고가 적은가**다.

읽는 순서는 다음과 같다.

1. **내가 낼 패**: 하단의 큰 카드 그림에서 즉시 식별한다.
2. **지금 판에 놓인 패**: 가운데의 여유 있는 공간에서 더미와 구별한다.
3. **서로 먹은 패**: 위·아래에서 같은 순서의 네 묶음을 비교한다.
4. **현재 형세**: 각 진영의 잔액·변동·점수와 사건 표식이 붙어 있다.
5. **운영 정보**: 판·점당 금액·메뉴는 상단 한 줄에서 필요할 때 찾는다.

카드 그림과 의미 있는 숫자가 주인공이다. 패널 제목·분류 설명·문턱 숫자·장식이 이들과 시선을 경쟁하지 않는다.

| 대상 | 참고 화면에서 실제로 보이는 특징 | 읽기 쉬운 이유 | 우리 화면에 적용할 것 |
|---|---|---|---|
| 전체 구도 | 상대 위, 내 정보 아래, 둘 사이에 넓은 판 | 누구의 패·수치인지 위치만으로 구별 | 같은 진영의 획득패·잔액·점수·사건을 한 덩어리로 배치. 반복 박스·역할 설명을 줄임 |

| 상단 | 판 정보와 메뉴가 짧은 한 줄 | 판을 읽는 공간을 빼앗지 않음 | 판/점당 금액/상대 이름과 메뉴만. 진행 문턱·개수 행·판 정보 버튼은 판에서 제거하고 메뉴 상세로 이동 |
| 바탕 | 넓고 단순한 색면, 영역 구분은 얕은 명도 차이 | 강한 색의 화투 그림과 흰 숫자가 배경에 묻히지 않음 | 우리 먹빛·한지·황동은 유지하되 금선 프레임·가죽 받침·비네트·눈에 띄는 펠트 결은 제거 |

### 캡처에서 잘못 일반화하지 않을 것

- 참고 손패는 6장이다. **10장을 한 줄에 겹쳐도 읽힌다는 근거가 아니다.** 앞선 구현은 이 차이를 놓쳤다.
- 참고의 바닥 같은 달은 일부 겹쳐 있다. 사용자는 우리 카드가 가려져 식별되지 않는 문제를 반복 지적했다. **가림 없는 식별을 우선**하고 그 겹침 자체는 복제하지 않는다.
- 참고는 손패·바닥·획득 요약의 역할에 따라 표시 크기가 다르다. 현재 사용자 확정은 우리 화면에서 전체48px 공통이다. 레퍼런스의 크기 비율을 그대로 측정해 정답으로 삼지 않는다.
- “심플함”은 필요한 숫자를 삭제한다는 뜻이 아니다. 주체·위치·위계를 일관되게 만들어 설명을 덜 읽게 하는 것이다.

## 3. 폰트와 숫자가 잘 읽히는 이유

참고 화면의 숫자는 획이 굵고 바탕과 명확히 분리된다. 잔액·점수는 크게, 단위는 함께 읽히게, 변동은 짧게 붙는다. 주요 숫자와 작은 보조 정보의 차이가 뚜렷하다. 캡처만으로 정확한 폰트 이름·굵기 값은 단정하지 않는다.

우리의 구현 기준:

- 로컬 번들 글꼴 하나. 12/14/16/24px 네 단계, 굵기400/600, 자간0, 숫자 tabular-nums.
- 잔액·점수24/600, 변동14/600, 이름14/400, 라벨·횟수12/400.
- 본문 한지색, 보조는 낮은 시각 강도, 강조 황동, 변동 적/청록. 보조 글자도 대비4.5:1 하한을 지킨다.
- 점수·금액·사건 횟수의 정렬선을 고정한다. 값이 바뀌어도 옆 요소를 밀거나 가리지 않는다.
- 글자 외곽선·그림자·큰 굵기만 따라 하지 않는다. 먼저 **같은 판을 얼마나 빨리 읽는지**를 비교한다.
- 화면 전체에 굵은 숫자, 최대 금액, 장식 테두리를 동시에 늘어놓지 않는다. 앞선 MAX_SAFE 캡처는 시각 평가와 경계 검사를 섞어 위계를 왜곡했다.

## 4. UX와 애니메이션

정지 캡처에서는 애니메이션 시간·곡선·프레임·입력 응답을 측정할 수 없다. 사용자가 원본의 애니메이션까지 높게 평가했다는 점은 요구로 기록하되, 원본 동작을 재현했다고 주장하지 않는다.

기존 기능과 결합해 적용할 원칙:

| 동작 | 전달해야 할 의미 | 적용/검증 |
|---|---|---|
| 패 내기 | 어떤 패를 냈고 어디로 갔는가 | 기존 WAAPI/FLIP 이동 기준점 유지. 이동 출발·도착이 읽히고 무관한 바닥패는 이유 없이 재배치되지 않아야 함 |
| 뒤집기·먹기 | 더미에서 나온 패와 먹은 결과의 연결 | 더미 위치 고정, 원 카드 그림 유지, 획득 스택에 도착. 중간에 카드가 잘리거나 사라지는 표현 금지 |
| 선택 | 지금 선택된 패와 실행 여부 | 누름 미리보기·스크럽 보정·놓음 한 번 실행. 선택 들림≤4px, 윗줄 가림0, 키보드 링 유지 |
| 뻑·흔들·폭탄 | 무슨 사건이 누구에게 일어났는가 | 도상/짧은 사건명/주체를 함께 읽게 함. 지속 카운트는 진영에 남기고 사건 효과는 유한하게 끝냄 |
| 고/스톱 | 판을 보면서 위험과 금액을 판단 | 비활성 손패 위 시트. 바닥·획득패·타이머 보존. 선택 필수·초점 순환·48px 두 버튼 |
| 바닥 선택 | 두 후보 중 무엇을 먹을 것인가 | 후보 카드에서 직접 탭, 후보 전체 노출, 나머지 약화. 별도 카드 선택창으로 시선 왕복을 만들지 않음 |
| 효과 줄이기 | 움직임 없이도 같은 결과를 이해 | reduced-motion 즉시/정적 전환. 펄스는 루트 strong일 때만. 금액 카운트업·상시 점멸 없음 |

## 5. 이번 작업의 실패 원인과 교정

1. **레퍼런스의 목적보다 숫자 규칙을 먼저 구현했다.** 겹침40%를 통과 기준으로 삼아 카드 도상이 가려지는 문제를 놓쳤다. 앞면100%를 먼저 확인한다.
2. **자연스러운 판을 고정 격자로 바꿨다.** 더미를 중앙에 둔 것만으로 레퍼런스를 반영했다고 보지 않는다. 빈 공간과 같은 달 관계까지 확인한다.
3. **경계 fixture만 보고 글자 크기를 조정했다.** 정상 판의 읽기 순서가 먼저이고 최대 금액은 별도 검사다.
4. **기존 CSS 위에 재정의가 누적됐다.** 겉모양을 다시 덮기 전에 Board/Hand의 높이·카드 창·정렬 규칙을 한 곳으로 정리한다. 겉보기와 실제 입력 사각형을 함께 측정한다.
5. **획득 요약과 행동할 패를 같은 겹침 문제로 취급했다.** 획득 스택은 요약+장수, 손패/바닥은 개별 식별과 선택이 목적이다. 허용 겹침을 구역별로 명시한다.

## 6. 적용 순서와 수용 증거

현재 구현은 진행 중이다. 이 문서 작성 자체를 검증 통과로 세지 않는다.

| 순서 | 작업 | 수용 기준 |
|---|---|---|
| 1 | 정상 판의 정보 위계 정리 | 한눈에 내 패·바닥·양쪽 획득4종·잔액·변동·점수·뻑/흔들 주체를 찾을 수 있음 |
| 2 | 손패와 바닥 가림 제거 | 손패10장·바닥8/10장 앞면100%, 월/종류 배지0, 같은 달 인접. 원본 SVG 비율 유지 |
| 3 | 자연스러운 바닥 배치 | 더미 기준점 유지, 카드 간 여백, 강제 행·열 정렬 없음, 기존 카드의 불필요한 점프 없음 |
| 4 | 같은 시각 문법 | 공통48px 카드, 지정 글자 단계/굵기, 같은 상자 경계/반경, 카드 그림자 한 종류 |
| 5 | 상태와 입력 | 대기/내 차례/선택/고스톱/정산 직전, 키보드·스크럽·취소·타이머·이벤트 가림0 |
| 6 | 비교·자동 검사 | 360×780·412×840·412×915 포함4폭×2엔진, JSON+캡처, 보이는 비조상 요소 겹침0(획득 요약/승인 예외 제외), 카드/글자 넘침0 |

바닥15장 이상에서만 같은 달을 두 장씩5px 겹치는 예외를 둔다. 별도 캡처로 확인하고 일반8/10장 캡처와 섞지 않는다. 손패에는 이 예외를 적용하지 않는다.

캡처 위치: `packages/web/test-results/pro-skin/`. 상용 참고 이미지와 비교용 합성 화면은 `.visual-source/`에만 두고 커밋하지 않는다. UI 전체 게이트와 실기기 검증은 별도이며 아직 완료로 표시하지 않는다.

## 7. 결정 이력

- 2026-09-30: 상용 맞고의 정보 위계·넓은 판·진영별 수치·획득4종 요약을 주 참고로 채택.
- 같은 날: 한 줄 손패/40% 노출 실험은 뒤 카드 식별 실패로 철회. 기존 UX-06의 비겹침 두 줄과 #164 월 묶음 비분할 유지.
- 같은 날: 5×3 고정 격자 실험은 자연스러움 부족으로 철회. 실제 카드 크기와 충돌 검사에 따른 비겹침 바닥 배치로 변경.
- 같은 날: 사용자 요청으로 본 문서를 먼저 정리하고, 이후 구현·캡처·검수의 판단 근거로 사용.
