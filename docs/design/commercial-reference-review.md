# 상용 맞고 레퍼런스 적용 기준

2026-09-30 · #171 · FR-12/14/40/46~50, NF-08 · UX-06/11/H05
사용자가 선호한 장점은 패·획득 내역·사건·점수·돈을 한눈에 읽는 정보 위계다.
원본은 `.visual-source/`에만 보관하며 이미지·폰트·코드를 복제하지 않는다.

| 장점 | 우리 화면에 적용하는 이유와 방법 |
|---|---|
| 진영별 정보가 모임 | 상대 위·나 아래에 획득4종·잔액·변동·점수를 모아 주체를 즉시 구별 |
| 큰 카드와 여백 | 손패·바닥48px와 획득 요약32px로 역할 구별, 손패6장 이하 한 줄·7~10장 비겹침 두 줄로 앞면100% 보존 |
| 자연스러운 바닥 | 같은 월은 독립 인접 셀에 나란히, 다른 월보다 좁은 간격. 묶음 단위로 분산 |
| 명확한 수치 위계 | 잔액·점수24/600, 부호 있는 변동14/600, 이름14/400, 보조12/400 |
| 획득4종 요약 | 같은 순서의 스택과 장수 하나, 상세 문턱은 메뉴로 이동 |
| 필요한 순간의 강조 | 중앙 고/스톱에 질문·실제 예상액·두 행동. 사건 콜아웃·박 스탬프는 PA-06 |
| 움직임이 행동을 설명 | 기존 WAAPI 이동·스킵·reduced-motion 보존. 정지 캡처로 원본 동작을 측정했다고 주장하지 않음 |

한 줄 손패·40% 노출 실험은 카드 식별 실패로 철회했다. 세부 결정·예외·높이 예산은 [ui-spec](ui-spec.md)에 통합한다.
검증은 정상 판(양쪽 획득4종·손패10장·바닥10장)과 최대 금액 경계를 분리해 캡처·교차 검사를 남긴다.
