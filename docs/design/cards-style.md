# 카드 스타일 가이드 — 클래식 리마스터

- 상태: 1단계 표본(2026-09-29). 시안 A·B는 사용자 검토에서 기각됐다. 이번 방향은 **익숙한 한국 화투의 구도와 인상을 충실히 새로 그리는 것**이다.
- 근거: `docs/design/cards-research.md`, `docs/research/rules-commercial.md` 1.1, spec 6.4·6.6·NF-03·NF-07·NF-08.
- 표본: `packages/web/cards-src/classic/`의 카드 10장(0·1·2·8·28·29·32·43·44·47), 뺏기 3피(50), 뒷면. `scripts/build-classic.mjs`가 `classic/optimized/`에 svgo 결과를 쓴다. `docs/design/preview-classic.png`은 현재 Commons와 새 그림을 비교한다.

## 1. 그림 원칙

1. **첫눈에 원래 알던 카드로 보인다.** 소나무·학·붉은 해, 매조, 벚꽃 휘장, 흑싸리·두견새, 난초·다리, 모란·나비, 홍싸리·멧돼지, 공산 명월·기러기, 국화·국진 술잔, 단풍·사슴, 오동·봉황, 비광·제비·비띠·번개의 도상과 전통적인 검은 면, 붉은 강조, 흰 여백, 노랑·파랑의 위치를 유지한다. 한국 순서인 **11월 오동·12월 비**를 따른다.
2. **원본 그림을 베끼지 않는다.** Commons SVG의 경로·윤곽을 복사하거나 트레이싱하지 않는다. 새 좌표로 손으로 그린 오리지널 벡터를 CC0로 낸다. 참조는 카드의 주제와 통상적인 색·배치에 한정한다.
3. **광과 띠의 익숙한 표식을 살린다.** 광은 빨간 원 안에 획으로 그린 `光`, 홍단·청단은 비단 띠 안에 획으로 그린 한글을 둔다. 초단·비띠는 글자 없는 붉은 띠다. 9월 국진은 술잔, 11월 쌍피는 오동, 12월 쌍피는 붉은 면·검은 구름·노란 번개로 읽히게 한다.
4. **모서리 색인은 작게.** 월·종류 표식은 그림을 보조한다. 큰 숫자·기호·종류별 배경색으로 그림을 대체하지 않는다. 앱의 기존 표식 오버레이와 겹치지 않도록 왼쪽 위에 조그맣게 두고, 2단계 런타임 전환 때 오버레이와 함께 다시 검토한다.
5. **44px을 기준으로 정돈한다.** 획 굵기와 식물·동물의 큰 실루엣을 정리하고 검은 면과 흰 면의 경계를 분명히 한다. 26px 획득패에서 드러나는 왼쪽 7~10px만으로도 월별 주색과 줄기 방향이 남아야 한다. 88px 확대에서는 작은 전통 장식이 보인다.
6. **새로움은 보너스와 뒷면에 집중한다.** 보너스는 뺏기 움직임을 별도 모티프로, 뒷면은 질 좋은 고전식 붉은 격자와 중앙 문양으로 그린다. 이 둘도 검정·빨강·흰색·노랑 팔레트에 묶는다.

## 2. 격자와 크기

| 항목 | 규칙 |
|---|---|
| SVG viewBox | `0 0 100 160` (가로:세로 = 0.625) |
| 카드 모서리 | 반경 4 단위. 바깥 붉은 테 4 단위, 흰 앞면 안쪽 x 4~96, y 4~156 |
| 모서리 색인 | 왼쪽 위 x 8~24, y 8~27. 주제 그림이 우선이며 색인은 점·짧은 띠·마름모·두 점으로만 종류를 암시 |
| 실제 카드 폭 | 획득패 26px, 바닥 44px, 손패 62px. 비교 확대 88px |
| 획득패 가시 폭 | 광·열끗·띠 10px, 피 7px. 왼쪽 변의 색과 선이 이 안에서 드러나야 함 |
| 중요한 선 | 2~3 단위 이상. 44px에서 약 0.9~1.3px. 장식선은 1.2 단위 이상 |

현재 런타임 `Card.svelte`는 103.2:168.2 비율과 별도 월·종류 표식을 쓴다. 1단계에서 런타임을 변경하지 않는다. 전체 세트 전환 시 비율과 오버레이를 같이 조정한다.

## 3. 팔레트와 광량

| 역할 | 색 | 쓰임 |
|---|---|---|
| 종이 | `#ffffff` | 전통적인 밝은 카드 앞면, 어두운 판에서 높은 대비 |
| 먹 | `#0b0b0b` | 큰 식물·산·구름 면과 동물 윤곽 |
| 주홍 | `#ec1c24` | 테두리, 해, 휘장, 띠, 12월 쌍피 |
| 황 | `#f5dc27` | 꽃술, 국화·번개, 뒷면 가는 테 |
| 청 | `#00a1d2` | 비·시냇물 등 전통의 푸른 요소 |
| 녹 | `#2f8b53` | 버들 잎 등 국소 보조색 |
| 뒷면 적갈 | `#b71118` | 붉은 뒷면의 깊이 |

색만으로 종류를 구분하지 않는다. 光 원, 띠의 글자, 술잔, 쌍피의 도상은 모양으로도 읽혀야 한다(NF-08). 어두운 UI에서도 흰 카드 바탕이 뚜렷하다.

## 4. 벡터·용량 규칙

- 앞면은 흰 바탕·붉은 테·그림 순으로 쌓는다. 좌표와 경로는 사람이 읽고 수정할 수 있는 SVG 원본으로 유지한다.
- `<text>`, filter, gradient, 외부 이미지·글꼴·URL은 쓰지 않는다. 한글·光 및 작은 숫자는 경로로 직접 그린다.
- 카드 1장 svgo 후 **8 KB 이하**. `scripts/build-classic.mjs`가 형식과 용량을 검사한다. 결과는 런타임 `public/cards/`에 쓰지 않는다.
- 기존 `svgo.config.mjs`와 Docker Node 이미지를 사용한다. Playwright 미리보기는 Docker e2e 이미지의 Chromium에서 기기 배율 2×로 생성하고 **1 MB 이하**로 유지한다.

## 5. 확인과 다음 단계

```sh
./dev.sh npm exec -w packages/web -- node scripts/build-classic.mjs
./dev.sh e2e -c scripts/card-preview.config.mjs --grep preview-classic
```

`preview-classic.png`에서 같은 샘플을 현재 카드와 44px, 26px 더미, 88px로 비교한다. 이 1단계는 전통 도상의 인식과 선명도를 판단하기 위한 샘플이다. 승인 후 2단계에서 나머지 38장과 다른 보너스 두 장을 그리고, 그때 카드 맵·라이선스 표시·런타임 자산을 함께 전환한다.
