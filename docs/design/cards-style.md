# 카드 스타일 가이드 (디자인 트랙 D1)

- 상태: **1단계 초안**(2026-09-29). 시안 A·B 중 하나를 사용자가 고르면 확정본으로 고치고 2단계(51장 + 뒷면 전부, 런타임 교체)로 넘어간다.
- 근거: `docs/design/cards-research.md`, spec 6.1·6.4·6.6·NF-03·NF-07·NF-08, plan.md 1.6.
- 생성기: `packages/web/scripts/card-drafts.mjs` (이 문서의 숫자는 모두 그 파일의 상수다. 문서와 코드가 다르면 코드를 고치고 이 문서를 맞춘다.)
- 미리보기: `docs/design/preview-A.png`, `preview-B.png`, `preview-compare.png`

## 1. 원칙
1. **44px에서 월과 종류를 1초 안에.** 모든 앞면의 왼쪽 위에 월 숫자와 종류 기호가 있다. 그림은 그다음이다.
2. **색만으로 구분하지 않는다(NF-08).** 종류는 기호의 **모양**(원·반원·마름모·띠 조각·칩 개수)으로 읽힌다. 색은 보조다.
3. **전통 도상을 지킨다.** 월별 식물·동물·물건은 한국 화투와 같다(학과 해, 술잔, 우산, 번개 …). 그림체만 현대적으로 바꾼다.
4. **평면 도형만.** filter·그라디언트·마스크·투명도·`<text>`를 쓰지 않는다. `<img>`로 한 번 래스터화된 뒤 WAAPI `transform`만 움직이므로 SVG 복잡도는 첫 디코드 비용에만 영향을 준다(plan.md 1.6).
5. **적은 색.** 시안마다 앞면 8색 + 뒷면 전용 1색. 앱 토큰(tokens.css)과 같은 OKLCH로 정의하고 생성 시 hex로 바꾼다.
6. **CC0 자체 제작.** 외부 그림·글꼴을 참고해 따라 그리지 않는다. 좌표는 생성기 코드가 전부 만든다.

## 2. 좌표계와 격자
| 항목 | 값 | 비고 |
|---|---|---|
| viewBox | `0 0 100 160` (비율 0.625) | 현재 Commons 103.2×168.2(0.614)와 1.8% 다르다 → 2단계에서 `Card.svelte`의 `aspect-ratio`를 `100 / 160`으로 바꾼다 |
| 모서리 반경 | 7 | 전체를 `clipPath`로 잘라 도형이 가장자리에서 깔끔하게 끊긴다 |
| 안전 여백 | 테두리 도형 3.5~4, 색인 6 | 광 금색 테두리는 inset 3.5(A)·4(B) |
| 색인 영역 `INDEX_ZONE` | x 0~38, y 0~58 | **모티프를 두지 않는다**(버들 줄기도 x 42 밖에서 시작) |
| 월 숫자 | 왼쪽 x 6, 위 y 8, 높이 26, 획 4.2 (A) / 도장 칸 x 4~31, y 5~36 안에 높이 ≤21, 획 3.6 (B) | 두 자리(10~12)와 `+3`은 칸 폭에 맞춰 줄어든다(B) |
| 종류 기호 | 중심 (16.5, 48) (B는 17.5), 지름 약 15 | x 30 안에 들어간다 |
| 더미 가시 폭 | 26px 카드에서 7px(피)·10px(그 외) = **27·38 단위** | 색인이 왼쪽 정렬인 이유. 피 더미에서도 숫자와 칩이 보인다 |

실제 크기 환산: 1 단위 = 0.26px(획득패) / 0.44px(바닥) / 0.62px(손패). 숫자 높이 26 → 6.8 / 11.4 / 16.1px.

## 3. 종류 기호 (두 시안 공통)
| 카드 | 기호 | 모양 | 색 |
|---|---|---|---|
| 광 | ● | 채운 원 r 7.6 + 먹 테두리 | 금색 |
| 비광 | ◐ | 왼쪽 반만 채운 원 ("반쪽 광": 비광은 광 3장 족보에서 약함) | 금색 + 먹 |
| 열끗 | ◆ | 마름모 15.6×18 | 먹(어두운 바탕에서는 한지색) |
| 국진 | ◆▮▮ | 마름모 + 작은 칩 2개 ("열끗 또는 쌍피") | 먹 |
| 띠 | ▰ | 기울어진 띠 조각 22×14 + 먹 테두리 | 홍단·초단·비띠 빨강, 청단 파랑 |
| 피 | ▮ | 칩 1개 (5.8×11.3) | 먹 |
| 쌍피 | ▮▮ | 칩 2개 | 먹 / 빨간 바탕에서는 한지색 |
| 보너스 3피 | ▮▮▮ (+ 숫자 `+3`) | 칩 3개. 2피 보너스는 `+2`와 칩 2개 | 한지색 |

- **피의 가치 = 칩 개수.** 피 더미를 훑을 때 쌍피·보너스를 개수로 센다.
- 홍단·청단·초단 구분: 모서리는 월 숫자(1·2·3 / 6·9·10 / 4·5·7)로, 그림 속 띠는 **먹 글자 획 3개의 유무**로 구분한다(홍단·청단은 획 있음, 초단·비띠는 없음). 전통 화투의 "띠에 글자" 단서를 추상화했다. 빨강·파랑은 적록 색각에서도 구분되며 명도도 다르다.
- 고도리(2·4·8월 열끗): 1단계에서는 표시하지 않는다. 2단계에서 ◆ 오른쪽에 작은 V(새) 표시를 시험하고 44px에서 읽히는지 본다.
- 뺏기(보너스): 가운데 그림에 "상대 패(오른쪽 흰 카드) → 내 쪽(왼쪽)으로 끄는 갈고리 화살표". 모서리에는 넣지 않는다(칩 개수가 가치).

## 5. 선 규칙
- 정보를 담는 선(숫자·윤곽·줄기)은 **2 단위 이상**(바닥 44px에서 0.9px). 숫자 획은 3.6~4.2.
- 시안 A 먹선(윤곽)은 2.4로 통일, 작은 꽃잎·잎은 1.8.
- 시안 B 붓 획은 채운 다각형이다: 중심선(캣멀-롬) + 굵기 곡선(시작 누름 → 최대 → 삐침), 결정적 PRNG로 ±9% 떨림. 가장 가는 끝도 선의 최대 굵기는 2.2 이상.
- 장식선(뒷면 안쪽 테)은 1.2 이상. 1.2 미만 선은 쓰지 않는다(래스터화 때 사라지거나 번진다).
- `stroke-linecap/linejoin`은 `round`.

## 6. 카드 종류별 표현
| 종류 | 시안 A | 시안 B |
|---|---|---|
| 광 | 금색 안쪽 테두리(3.4) + ● 기호 + 큰 해/달/우산 | 금색 안쪽 테두리(3) + ● 기호 + 주칠 해/우산 |
| 열끗 | 동물·물건이 주인공, 먹선 평면 | 붓 몇 획으로 동물 실루엣 |
| 띠 | 세로 띠(폭 17, 끝 제비꼬리) + 먹 글자 획 3개(홍·청) | 흔들리는 붓 띠(폭 17) + 먹 점 3개(홍·청) |
| 피 | 식물만, 여백 많음 | 식물만, 여백 가장 많음 |
| 12월 쌍피 | 빨간 바탕 + 먹 구름 + 금 번개 (한국 화투의 "빨간 12월 쌍피" 단서 유지) | 주칠 바탕 + 먹 구름 두 획 + 먹·금 번개 |
| 11월 쌍피(2단계) | 오동잎을 바탕색 반전(먹 바탕 + 한지색 잎)으로 다른 피와 구별 | 같은 방식, 먹 바탕 |
| 보너스 | 보라 바탕 + 큰 숫자 + 뺏기 갈고리(금) | 먹 바탕 + 큰 숫자 + 뺏기 갈고리(주칠) |
| 뒷면 | 한지색 테 + 빨강 + 청해파 무늬 + 가운데 먹 원과 흰 꽃 | 한지색 테 + 검붉은 바탕 + 한지색·금 안쪽 테 + 금색 일원상 + 주칠 도장 |

## 7. 월별 모티프 계획 (2단계에서 그릴 것)
1월 학·해·소나무(완료) / 2월 매화 가지 + 꾀꼬리 / 3월 벚꽃 덩어리 + 휘장(광) / 4월 늘어진 흑싸리 + 두견새 / 5월 붓꽃 + 다리(열끗) / 6월 모란 + 나비 / 7월 홍싸리 + 멧돼지 / 8월 억새 언덕 + 보름달(광) + 기러기 셋 / 9월 국화 + 술잔(완료) / 10월 단풍 + 사슴 / 11월 오동잎 + 봉황(광) / 12월 버들 + 우산·제비·번개(완료).
- 피 2장이 같은 월에 있을 때는 배치(좌우 반전, 잎 개수)를 바꿔 두 장이 똑같지 않게 한다(전통 화투도 두 피가 조금 다르다).

| 항목 | 예산 | 시안 A | 시안 B | 현재 Commons |

| 표본 12장(11장 + 뒷면) | — | 27.0 KB | 37.6 KB | 132 KB |

- 생성기가 카드마다 8 KB를 검사하고 넘으면 실패한다. svgo 설정은 런타임과 같은 `packages/web/svgo.config.mjs`.
- 좌표는 소수 1자리. 100×160 좌표계라 0.1 단위는 손패(62px) 3× 화면에서도 0.2px 미만.

## 9. 파이프라인
```
./dev.sh npm exec -w packages/web -- node scripts/card-drafts.mjs   # SVG (결정적, 같은 코드 → 같은 바이트)
./dev.sh e2e -c scripts/card-preview.config.mjs                      # PNG 미리보기 (도커 e2e 이미지의 Chromium)
```
2단계(선택된 시안 확정 후, 런타임 변경 PR):
1. `card-drafts.mjs`의 한 시안을 51장 + 뒷면으로 확장하고, 출력 경로를 `cards-src/`로 옮긴다.
2. `src/cards/map.json`의 `source`를 전부 `original`로 바꾸고 `build-cards.mjs`의 Commons 내려받기·SHA-1 대조를 제거한다.
3. `Card.svelte`: `aspect-ratio: 100 / 160`, 런타임 표식 오버레이(`.mark`) 제거(그림에 들어 있음). 화면 읽기 이름(`cardLabel`)은 그대로.
4. `attribution.ts`·License 화면·`public/cards/LICENSE`: CC BY-SA 항목 삭제, 전부 CC0. spec 6.6·NF-07 문구와 code-refs.md 4장 갱신.
5. 갤러리 스냅샷(`e2e/__screenshots__`) 재생성, axe 재확인.
