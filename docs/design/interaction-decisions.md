**확정**은 1·2차 인터뷰에서 사용자가 직접 선택한 결정, **기본 채택**은 2차 인터뷰에서 기존 권고안을 일괄 채택한 결정(사용자 거부 시 변경), **추가 권고**는 이번에 새로 제안한 시간 초과 정책·세부 구현 계약이다. **기존**은 현행 명세다. 상용의 ‘일반적/일부/없음/미확인’은 출처의 판정이고 제품 채택 상태와 다르다. 확정 항목은 다시 승인받지 않는다. 아래 대안은 비교 기록이지 확정 결정을 되돌리는 질문이 아니다.

## 2. 자동 진행·입력 계약

### 2.1 동등성·자동 선택 계약 초안

| 판단 단계 | 권고 계약 / 반례 |
|---|---|
| 동등한 대상 | 현재 자기 `pending.kind=target`의 legal 후보, 동일 달·동일 종류·동일 피 가치·동일 족보 기여·특수 역할 없음. 최초 범위는 **같은 달 일반피 1가치 두 장**. 표준 카드 카탈로그에서 ID/그림만 다른 쌍 |
| 다른 가치 | 피1/쌍피2, 열끗/띠, 국진/일반피, 홍단/기타 띠처럼 미래 족보·역할 차이가 있으면 묻기. 현재 0점 증가가 같다는 이유로 생략하지 않음(S1~S5). 월이 다르면 애초 같은 target 후보가 아님 |
| 우선순위 | 동등 후보 중 ID 오름차순을 **Q01 기본 채택**. 화면 좌우·DOM 순서·좌석·랜덤·더미 정보에 의존하지 않음. 이는 고득점 선택이나 상용 우선순위의 재현이 아님 |
| 질문 발생 시점 | 낸 패와 뒤집은 패에서 생긴 target 모두 같은 정책. 따닥 가능성을 미리 알아서 생략하는 것이 아님. 전체 무더기 획득은 target 비교가 아니라 엔진의 pile 처리 |
| 입력·재연결 | 권위 스냅샷/액션 ID로 1회, 기존 전송·중복 방지 경로 재사용. 렌더마다 재전송하거나 호스트·게스트가 같은 좌석을 각각 자동 실행하지 않음. 솔로/호스트/게스트 동일 정책, 이벤트·정산·로그는 수동 선택과 동일 |

### 2.2 ‘유일 합법 수’ 자동 진행 계약 초안 (D08)

C02 자동 진행은 확정이다. 동등 선택·강제 수 실행만으로 힌트 사용 이력을 올리지 않는다.

| 상황 | 동작 / 이유 |
|---|---|
| 자기 play pending, legal에 일반 play 또는 flipOnly 하나뿐 | 직전 이벤트 재생 완료 뒤 그 수를 1회 자동 실행. ‘자동 진행’ 문구와 일반 카드 경로 유지. 추가 확인/타이머 없음 |
| 손패1 + 폭탄패 토큰 / 손패3 + bomb / 여러 보너스 | 모든 합법 행동을 세므로 하나가 아님. 손패 장수나 매칭 가능 장수만 보고 자동 내지 않음 |
| target 2개가 규칙상 동등 | legal 길이는 2여도 C01로 자동 대표 선택. 가치가 다르면 수동. 자동치기 일반 옵션을 켰다는 전제 없음 |
| 흔들기·국진·고스톱·총통 | C02 유일 수 자동 진행 대상 아님. 국진 자동 모드·엔진의 자동 총통은 기존 처리. P2P에서 시간이 끝난 경우는 별도 U06 정책·명세 개정 대상 |
| 판 종료 후 legal에 push 하나 | **자동 실행하지 않음**. ‘받기’는 세션 API라 legal 배열 밖에 있음. 전체 사용자 선택이 하나라는 뜻이 아님 |
| 메뉴/상세 보기·백그라운드·연결 단절·응답 대기 | C02의 새 자동 입력은 보류 **U14 기본 채택**. 복귀한 최신 뷰에서 다시 판정, 오래된 예약 액션 폐기. 상대/AI의 이미 수락된 진행을 되돌리지는 않음(U14) |
| 연속 강제 수·보너스 보충 | 매 권위 뷰마다 다시 판정. 여러 턴을 몰아서 전송하지 않고 스킵 입력을 카드 입력으로 재사용하지 않음 |

### 2.3 P2P 기본 10초와 시간 초과 — 명세 개정이 필요한 추가 권고

**U06 확정: P2P 기본 10초·호스트 끄기/조정.** 기존 FR-16 개정 필요. 아래 초과 행동·시계 경계는 **추가 권고**이며 #123(v0.2.3)이 소유한다. 솔로에는 적용하지 않는다.

[상용 조사 §6](../research/interaction-conventions.md#6-p2p-제한시간과-시간-초과-추가-조사)의 피망 규정은 **접속 종료 시 컴퓨터 대행**만 입증한다. 3사의 평상시 제한 초 수·합법 수 우선순위·선택 프롬프트 기본값은 미확인이다. 따라서 ‘상용도 10초/자동 스톱’이라고 설명하지 않는다.

| 대상 | 초과 시 추가 권고 | 이유 / 대안 |
|---|---|---|
| 일반 내기 | 최신 해당 좌석 공개 뷰의 합법 일반 play 중 **카드 ID 최소** 1장. play가 없고 flipOnly가 합법이면 뒤집기. C02가 유일 수를 이미 실행했다면 아무것도 보내지 않음 | 고정 순서는 재현 가능하고 사람 대전에서 AI 전략 대행을 피함. 합법 bomb가 함께 있어도 자동 폭탄은 하지 않음. 대안: 무작위(재현·검증 부담), AI 대행(공정성·힌트 정책 변경) |
| 바닥 target | 동등하면 C01로 즉시 생략. 가치가 다르면 정상 시간 동안 묻고, **초과 때만 ID 최소 합법 대상** | C01 ‘가치 다르면 묻기’의 시간 초과 예외이므로 명세에 명시. UI에 초과 행동 안내. 대안: 점수 우선(전략 대행), 무제한 대기(제한 목적 상실) |

| 흔들기 | **그냥 내기(accept=false)**로 이미 선택한 패 진행 | 미응답 상태에서 패 공개를 강요하지 않음. 바텀 시트에 남은 초·초과 시 그냥 내기 표시. 대안: 자동 선언 |
| 국진 ‘매번 묻기’ | **현재 공개 획득패에 표시된 열끗/피 위치 유지**에 해당하는 합법 행동 | 자동 최적 모드는 질문 자체가 없음. ask의 시간 초과까지 최적화로 바꾸지 않음. 대안: 자동 최적 또는 항상 피 |
| 총통 계속/끝내기 | 합법이면 **끝내기** | 확보된 종료 기회를 보존. 대안: 자동 계속. 엔진이 이미 자동 처리한 경우 새 액션 없음 |
| 선 고르기·밀기/받기·다음 판·재충전 | **제한시간 적용 제외, 명시 선택 대기** | 판 시작/정산·세션 선택은 U15의 결과 확인을 보존. push 하나만 legal이어도 받기는 세션 API에 따로 있음. 대안: 자동 받기·다음 판은 별도 제품 결정 필요 |

### 2.4 폭탄 탭·길게 누르기와 취소 지연의 충돌 해소

Q02 확정이 U02의 일반 미리보기보다 우선한다. 합법 폭탄 표시 카드의 탭은 폭탄, 길게 누르기는 그 카드 한 장 내기다. 일반 카드의 길게 누르기는 여전히 미리보기만 하고 내지 않는다. **구체 제스처 계약 제안:** 현재 길게 누르기 문턱에 도달하면 ‘한 장 내기’를 알리고 같은 카드에서 손을 뗄 때 한 번 실행한다. 포인터 취소·카드 밖 이탈·뷰 교체는 취소하며 뒤따르는 합성 click으로 폭탄이 추가 실행되지 않아야 한다. 키보드/보조기술에는 ‘한 장 내기’ 보조 행동을 제공한다.

U01의 120ms 지연은 **옵션이며 신규 기본은 즉시**다. 옵션을 켠 경우 일반 탭/폭탄 탭 모두 전송 전 재탭으로 취소할 수 있지만, 이미 호스트/엔진이 수락한 행동을 되돌리는 기능은 아니다. 이동 중 입력 잠금(U22), 48px 터치 영역, 폭탄 가능/확정 획득/초점의 합성 라벨(U21)을 #104 화면 구조에서 함께 검증한다.

## 4. 확정 획득 — 사용자 정의와 API 경계

### 4.1 판정 정본

**손패 카드 X의 달 M이 바닥에 짝이 있고 `unseenCards(view)`에 M이 없고 상대 `revealed` 손패에도 M이 없으면 ‘확정 획득’.** 짝이 있고 unseen 또는 상대 revealed에 M이 하나라도 있으면 ‘먹을 수 있음’, 짝이 없으면 표식 없음. 내 손패·바닥·양쪽 획득패에 네 장 모두 존재해야 한다는 추가 조건을 삭제했다. C05·#109 수용 기준은 이 문장과 동일하다.
`unseenCards`는 상대의 **숨은** 손패와 더미의 집합이며 상대 `revealed`·현재 턴 공개 카드는 제외한다. 따라서 **상대 revealed의 M 부재를 별도로 검사**한다. CF09는 상대 공개 손패가 바닥 짝을 먼저 가져갈 수 있으므로 ‘먹을 수 있음’이다. 자기 revealed가 아니라 `view.seats[상대 좌석].revealed`를 검사한다.

| 경계 | 계약 |
|---|---|
| 활성 표시 수명 | 자기 차례·play pending·X가 legal인 최신 안정 뷰에서 표시. busy/연결 단절·늦은 반환에는 숨김. 이는 분류 정의에 추가하는 카드 소유 조건이 아님 |
| 바닥 짝 | `matchPreview`의 take/choose/pile. place·보너스·flipOnly는 이 월 짝 분류 대상이 아님 |
| 의미 | 지금 X를 낼 때의 분류이며 미래 영구 소유·승리·점수·바닥 둘 다 획득을 보장하지 않음. 자동 내기 명령도 아님; 가치 다른 target은 계속 질문(C01) |
| 표시 | 기본·상세에서 확정=색 A+실선+이름, 먹기 가능=색 B+점선+이름. CF01/02 동일, CF09는 먹기 가능. 힌트 끔에는 숨김; 실제 표시를 FR-50에 기록. 세부 접근성은 #115 |

### 4.2 정상·경계·반례

H/F/C/U는 해당 달의 내 손패/바닥/양쪽 획득패/unseen 장수다. 보너스는 달이 없으며 국진 위치 변경은 카드 ID를 바꾸지 않는다. 규칙 기대값은 §12 R1·R7·B1~4·S1~5·E1·E6·E9~11·G1~2, 분류는 C05다.

| ID / 유형 | 공개 상황 | 기대 표시 / 이유 | 기존 공개 API로 계산 가능한가 |
|---|---|---|---|
| CF01 정상 (a) | H1/F1/C2/U0, 획득2는 어느 좌석에 있어도 됨 | **확정 획득**. 짝이 있고 U0·상대 revealed M0. CF02와 같은 색·라벨 | 가능: legal→play 확인, preview take, unseen·상대 revealed M 필터 |
| CF02 정상 (b) | H2/F2/C0/U0, 2장 폭탄 기본 끔 | **확정 획득**. 지금은 한 장 내고 바닥 하나 선택; 손의 두 장 모두 같은 표식. ‘따닥 확정’은 아님 | 가능: 각 play·preview choose·unseen M 필터. 두 후보 가치는 별도 C01로 판정 |
| CF03 정상 | H3/F1/C0/U0, bomb도 합법 | **확정 획득**과 폭탄 가능을 구별. 일반 play도 보존, bomb 선택 시에만 3장 동시 | 가능: legal play/bomb·preview take·unseen M 필터. preview 자체는 bomb의 결과 API가 아님 |
| CF04 정상 | H1/F3/C0/U0, 뻑 또는 자연뻑 무더기 | **확정 획득**. 기본 M 3장과 X로 4장; 묻힌 보너스는 월 집계에서 제외 | 가능: preview pile·floor.kind/cards·unseen. 피 뺏기 부가효과를 이 표식에서 보장하지 않음 |

| CF06 경계 | CF02에서 2장 폭탄 켬/끔 전환한 별도 세션 | 두 세션 모두 **확정 획득**. 켬 세션에서만 합법 bomb 표시 | 가능: legal 결과 소비. 클라이언트가 규칙을 켜서 가상의 폭탄을 만들지 않음 |

## 6. 검증 기록

변경은 조사·결정 문서뿐이며 코드·자산·의존성은 수정하지 않는다. 상용 출처 확인·미확인 구분은 [조사](../research/interaction-conventions.md)에 유지한다.
이전 head `79af467`에서 Docker npm ci/lint/check/test/test:browser/build/E2E/Android 전체 통과(브라우저 278, E2E 94 통과·4 건너뜀, dist 1187.2KiB/1536KiB·외부 URL 0). 리뷰도 같은 head에서 회귀 결과를 확인했다. 이번 문서 수정은 `export PATH="$HOME/.local/bin:$PATH"` 후 개발 이미지 lint:fix·lint 및 git diff --check 통과. 31문항·16사례·27개 유지 이슈와 10개 not_planned 종료를 대조했다. 코드 불변이므로 전체 회귀 검사를 반복하지 않았다.
실기기·음원 청취는 미실시. 기존 코드 검사 결과를 새 상호작용의 구현 완료로 기록하지 않는다.
