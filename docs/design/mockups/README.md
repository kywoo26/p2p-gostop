# 보존한 디자인 목업

A · 사이 시각 방향의 정적 화면 6장과 전문 스킨 평가 화면 8장·아바타 contact sheet를 보존한다. 채택 결정은 [art-direction 결정 이력](../art-direction.md#결정-이력), 실제 화면 규범은 [ui-spec](../ui-spec.md)에 있다. B/C 비교안과 일회성 렌더러·폰트 조사 산출물은 정리했다. 각 PNG는 150 KiB 이하이며 전체 목업 PNG는 1 MB 이하이다.

| A · 사이 | 화면 |
|---|---|
| [ink-home](ink-home.png) | 홈 |
| [ink-game](ink-game.png) | 판·대상 선택 |
| [ink-gostop](ink-gostop.png) | 고/스톱 |
| [ink-ppeok](ink-ppeok.png) | 뻑 |
| [ink-jjok](ink-jjok.png) | 쪽 |
| [ink-settlement](ink-settlement.png) | 정산 |

전문 스킨 8화면·아바타는 [pro README](pro/README.md)에 있다. 이 PNG는 문서용 평가 자료이며 앱 dist에는 포함하지 않는다. 앱의 갤러리는 웹 컴포넌트와 번들 자산에서 직접 생성된다. 재압축은 원본 색상을 32~48색 팔레트로 근사해 수행했으며 원본 이력은 Git에서 확인할 수 있다.

카드 그림이 포함된 화면에는 [Commons Hwatu 저작자·CC BY-SA 4.0 고지](../../../packages/web/public/cards/ATTRIBUTION.md)가 적용된다. 전문 자산은 [pro 고지](../../../packages/web/public/pro/NOTICE.md)와 [art-direction](../art-direction.md)을 따른다. 실기기 결과는 사람이 [device-test](../../device-test/procedure.md)에만 기록한다.
