# 맞고 상호작용 관례 조사

2026-09-29 · 기준 main `ca66ce9` · spec FR-14~17·FR-46~50·§6 / plan M3·M6·D2.
목적은 Galaxy v0.2.1 피드백에 대한 상호작용 설계다. **게임 규칙의 기대값은 [rules-commercial.md §12](rules-commercial.md#12-권장-기본-규칙-세트)만 사용**한다. 상용 UI 관찰을 규칙 변경의 근거로 사용하지 않는다. 제품 결정·인터뷰와 공개정보 판정 초안은 [interaction-decisions.md](../design/interaction-decisions.md)에 있다.

## 3. 흔들기: ‘정석이 무엇인가’에 대한 답

**2차 인터뷰 확정(Q03): 낼 패 탭 뒤 바텀 시트 ‘흔들고 내기 / 그냥 내기’를 선택한다. 응답 전에 자동 선언하지 않는다.** 확인 가능한 한게임 관례와 우리 E11의 ‘선택’에 맞춘 정석이다. 3사 공통의 중앙 팝업을 입증한 것은 아니다.

| 쟁점 | 출처에서 확인된 사실 | 판단 / 남은 공백 |
|---|---|---|
| 선언하지 않고 낼 수 있나 | H1은 같은 월 3장·바닥에 먹을 패가 없을 때 패를 선택하면 흔들기 또는 그냥 내기가 가능하다고 명시 | **가능(한게임)**. 무조건 자동 흔들기를 정석으로 권할 수 없음 |
| 자동인가 | H1은 선택 경로를 설명. P2는 공개하면 배수라는 규칙만 설명 | 기본 자동 선언을 뒷받침하는 자료 없음. 한게임 수동 경로에서는 강제 자동 아님; 별도 자동 설정은 미확인 |
| 확인 팝업이 있나 | H3는 선언 후 3장을 보여 주는 결과 통지 | 선언 전 질문 팝업의 모양·위치·기본 선택은 **미확인**. 결과 통지를 예/아니오 확인창으로 잘못 인용하지 않음 |
| 우리 제품의 정석 표현 | [§12 E11](rules-commercial.md#124-특수-이벤트)은 선택. 기존 FR-16은 기본값·타이머 없음이나 U06의 P2P 10초 확정으로 개정 필요. spec §6.3·UX-09의 예약 선택 구역과 정합 필요 | 선택한 바텀 시트를 예약 영역·안전 영역 안에 배치해 손패를 가리지 않도록 설계. ‘상대에게 같은 달 패를 공개, 이기면 배수’ 설명. 미선언·선언 전 후보는 상대에 숨김 |
| 채택 상태 | 1차는 정석 조사 요청, 2차는 패 탭 뒤 두 선택 바텀 시트로 **확정** | 상용과 동일한 팝업이라는 주장은 아님. P2P 시간 초과 ‘그냥 내기’는 별도 추가 권고. 폭탄 배수(E9)와 수동 흔들기 선언(E11)을 구별 |

## 4. 사운드 추가 조사와 방향

사용자 1차 인터뷰로 **신규 기본값: 효과 강조 + 소리 켬 + 진동 켬**은 확정됐다. 아래 음원 선정·길이·혼합 방식은 설계 권고이며 청취 승인/구현 완료가 아니다. Android 브리지 진동만 지원하고 iPhone Safari에는 진동을 호출하지 않는다. 2차 인터뷰에서 실물음+짧은 합성음(Q08), 주요 사건 진동(U11), 배경음 없음(U12), 기존 끔/절제 등 저장값 보존(U13)은 기본 채택했다. 개별 파일 선정과 청취는 남은 구현 과제다.

OFL은 [SIL Open Font License](https://openfontlicense.org/)라는 **폰트용 라이선스**다. 사운드는 공식 페이지에서 CC0를 확인한 후보를 사용하고, 기존 Pretendard의 OFL 고지와 분리한다. 아래는 라이브러리·분류·배포 조건 확인이며 다운로드 묶음 안의 특정 파일 선정이나 청취 평가는 아직 없다.

| 후보 / 공식 출처 | 확인한 배포 표시 | 사용 제안 / 한계 |
|---|---|---|
| **1순위 [Kenney Casino Audio](https://kenney.nl/assets/casino-audio)** | CC0, 50개, card/dice/chip/foley 분류 | 카드 놓기·뒤집기·피 이동의 실물감 기반. 화투에 맞는지는 후보 파일 청취 후 판단 |
| [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds) | CC0, 130개, impact/foley 분류 | 폭탄·뻑의 짧은 타격층. 저음만으로 사건을 구분하지 않고 리듬·중역 어택을 함께 사용 |
| [Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds) | CC0, 100개, interface/click/button 분류 | 선택 확정·고/스톱의 짧은 보조음. 카드음과 구분, 상용 캐릭터 음성 복제 없음 |
| 기존 `packages/web/src/game/sound.ts` 합성 | 저장소 자체 구현(외부 음원 추가 없음) | CC0 카드음 + 기존 합성 음정/리듬 조합 권고. 음원 수·번들 크기를 줄이고 사건 구분 확보 |

**방향: 마른 카드 타격 + 짧은 저음층 + 사건별 리듬 차이.** ‘역동적’은 음량을 일괄 증폭하거나 턴을 오래 멈추는 뜻으로 쓰지 않는다. 폭탄과 총통처럼 드문 사건에만 복합음을 주고, 평상 카드음은 짧게 유지한다. 외부 스트리밍 없이 선정 파일만 번들하며 ui-spec VD-01~04의 **소리 48KiB / 전체 dist 1.5MiB** 예산 안에서 결정한다.

| 사건 / 신호 | 짧은 음 설계 후보 | 길이 목표(자체 제안) / 반복 규칙 |
|---|---|---|
| 카드 내기 / 뒤집기 / 획득 | 마른 탁 / 얇은 종이 마찰 / 짝 소리로 역할 구분 | 각 40~100ms / 60~120ms / 70~140ms. 다장 획득은 묶음당 1회 |
| 뻑 / 자뻑 회수 | 낮고 막힌 탁 / 획득음에 짧은 해소음 | 100~180ms / 120~200ms. 자뻑에 기본 획득음 중복 금지 |
| 쪽 / 따닥 | 밝은 짝 1회 / 간격 있는 2타 | 100~180ms / 전체 160~240ms. 따닥 2타는 한 사건의 의도된 리듬이라 일반 중복 억제로 하나를 지우지 않음 |
| 쓸 / 피 뺏기 | 짧은 쓸림+마무리 탁 / 가벼운 이동음 | 150~250ms / 80~140ms. 쪽+쓸+뺏기는 주 사건 1개와 이동 보조로 합성 |
| 흔들기 / 폭탄 | 종이 2박 / 묵직한 팡+짧은 카드 확산 | 150~240ms / 180~300ms. 선언·폭탄 확정 뒤만, 가능 배지에는 무음 |
| 고 / 스톱 | 짧은 상승 2음 / 내려앉는 종결음 | 140~220ms / 180~280ms. 버튼 노출 때가 아니라 선택 수락 뒤 |
| 총통 / 판 승리·패배·나가리 | 짧은 강조 3박 / 구별되는 종결 동기·중립음 | 220~320ms / 200~350ms. Stop→RoundEnded→Settled 연속을 한 종결로 합침 |
| 즉시 정산 / 국진 이동 / 선택 요청 | 작은 정산음 / 문구만 / 초점·문구만 | 100~180ms / 무음 / 무음. 선택을 재촉하는 반복음 없음 |

| 구현 인계 기준 | 확인할 내용 |
|---|---|

## 5. 확인되지 않은 관례를 닫는 방법

| 미확인 항목 | 필요한 추가 1차 증거 |
|---|---|
| 동등 선택 생략·우선순위 | 같은 달 일반피 2장 / 일반피+쌍피 / 서로 다른 종류를 낸 뒤까지 보여 주는 공식 무편집 시연. 카드 위치 교환 반복으로 우선순위를 분리 |
| 폭탄·흔들기 입력 | 후보 표시→실제 탭→선언/미선언→결과까지, 앱 버전·설정·일반/자동치기 모드를 함께 확인. 팝업 장면 생략 영상은 불충분 |
| 고/스톱·유일 수 | 선택 직전부터 응답까지 위치·예상액·초 수와 시간 경과를 보여 주는 자료. 자동치기 버튼 존재만으로 결론 금지 |
| 확정 짝·음향 | 표식의 의미를 정의한 공식 도움말 또는 조건별 공식 시연, 사건별 음을 들을 수 있는 원본. 불명확한 화살표·홍보 합성은 불충분 |

이 공백은 사용자 확정 결정의 시행을 막는 조건이 아니다. 상용 공통 구현이라고 주장하지 않고 자체 제품 결정으로 추진한다.

## 6. P2P 제한시간과 시간 초과 추가 조사

2차 사용자 결정은 **제한시간 도입·기본 10초·호스트 끄기/조정**이다. 아래 상용 관례 조사로 10초의 보편성이나 자동 선택 알고리즘을 입증한 것은 아니다. 2026-09-29 공식 도움말·운영정책·스토어를 ‘제한시간/시간초과/자동치기/접속 끊김’으로 추가 확인했다. 사용자 블로그·위키의 ‘보통 자동 스톱’ 같은 설명은 판정 근거로 쓰지 않았다.

| 항목 | 한게임 신맞고 | 피망 뉴맞고 | 윈조이 | 판정 / 1차 출처 |
|---|---|---|---|---|
| 평상시 생각 시간 기본 초 수·조정·끔 | H1·H2·H5에서 미확인 | P1·P3에서 미확인 | W1에서 미확인 | **미확인**. 10초는 우리 사용자 결정 |
| 무응답 때 자동으로 내는 카드 우선순위 | 자동치기 버튼만 확인(H2) | 자동치기 버튼만 확인(P1) | 미확인 | **미확인**. 버튼 존재는 시간 초과 자동 내기의 증거가 아님 |
| 고/스톱·흔들기·국진·밀기 초과 기본 선택 | 미확인 | 미확인 | 미확인 | **미확인**. 흔들기 수동 선택(H1), 국진 조건부 질문(P2)만으로 만료 동작을 유추할 수 없음 |
| 접속 종료 시 대행 | 이번 자료에서 미확인 | 접속이 끊긴 뉴맞고/맞고를 컴퓨터가 대행하고 결과를 잔액에 반영; 판 종료 전 재입장 시 이어서 플레이 | 미확인 | **일부(P4)**. [피망 운영정책 제8조 제2항](https://www.pmang.com/policy/webgame), 적용일 2025-08-26; 비의도적 접속 끊김도 포함. **평상시 무응답 타이머나 AI의 구체 선택 규칙은 명시하지 않음** |
| 우리 오프라인 P2P에 그대로 이식 | 해당 없음 | 접속 종료 대행·머니 반영은 상용 온라인 서비스 정책 | 해당 없음 | 정책 관찰은 게임 규칙 정답이나 네트워크 설계 요구사항을 대체하지 않음. 연결 단절과 정상 연결의 생각 시간 만료를 분리 |

제품 권고는 [결정 §2.3](../design/interaction-decisions.md#23-p2p-기본-10초와-시간-초과--명세-개정이-필요한-추가-권고)에 명시했다. 일반 내기/target은 고정 합법 카드 순서, 고스톱은 스톱, 흔들기는 그냥 내기, 국진 질문은 현재 위치 유지, 총통은 끝내기, 판 사이 밀기/받기·다음 판은 수동 대기가 **우리 추가 권고**다. 아직 공식 영상에서 초과 전후·모드·버전을 함께 확인하지 못했으므로 ‘상용 정석’으로 표기하지 않는다.
