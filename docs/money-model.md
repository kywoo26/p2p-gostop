# 머니 모델: 시작 잔액·점당 금액 기본값 (spec MN-03·MN-04, AC-10)

작성: 2026-09-28 · 데이터: `tools/sim` 셀프플레이 · 기본값 상수: `packages/ai/src/money-defaults.ts` (`MONEY_STATS`, `START_BALANCE_TABLE`, `suggestedStartBalance`)

> 상태: **표준 프리셋만 산정 완료.** 정통·아케이드는 **표준값 준용, 추후 재산정**(M6). 사용자 우선순위 변경(P2P 대전 우선)으로 시뮬레이션을 중단했다(6절).

## 1. 결론 (설정 기본값)

30판 세션에서 **파산 확률 ≤ 5%** 가 되는 최소 시작 잔액을 보기 좋은 단위로 올린 값. 점당 금액에 선형 비례한다(MN-04: 자동 제안, 수동 변경 가능). 단위는 가상 단위(기본 "냥", MN-06).

| 프리셋 | 점당 50 | 점당 100 (기본) | 점당 200 | 점당 500 | 점당 1000 | 근거 |
|---|---|---|---|---|---|---|
| 표준 | 75,000 | 150,000 | 300,000 | 750,000 | 1,500,000 | 산정 (파산 확률 4.5%) |
| 정통 | 75,000 | 150,000 | 300,000 | 750,000 | 1,500,000 | 표준값 준용, 추후 재산정 |
| 아케이드 | 75,000 | 150,000 | 300,000 | 750,000 | 1,500,000 | 표준값 준용, 추후 재산정 |

(표의 행은 `tools/sim/test/money-doc.test.ts`가 `START_BALANCE_TABLE`과 대조한다.)

설정 도움말 요약: "상용급 AI끼리 3,000판을 둔 결과, 점당 100냥이면 한 판에 보통 1,600냥(중앙값)이 오가지만 고를 여러 번 부른 판은 수만 냥 이상으로 커집니다. 시작 잔액 150,000냥이면 30판 동안 잔액이 바닥날 확률이 약 4.5%입니다."

## 2. 방법

1. **셀프플레이**: 상용급(최종 설정: 결정화 몬테카를로 + 순차 반감, 반복 2000, 가중치 v2, `docs/ai-tuning.md`) 대 상용급, `tools/sim --mode session`, 세션 30판 × 100세션 = **3,000판**, 20코어 worker_threads, 약 12분. spec MN-03은 ≥ 10,000판을 요구하나 시간 제한으로 3,000판(6절). 세션 안에서 선(직전 승자)·나가리 배수(×2, 상한 ×8)·판 번호(대박판)가 이어지고 첫 판은 선 고르기부터.
2. **판별 순액**: 한 좌석 관점의 판 정산(±finalPoints) + 그 판 즉시 정산(첫뻑·연뻑·첫따닥 등), 점 단위. 나가리 판은 0(다음 판 배수로 반영).
3. **파산 몬테카를로**: 두 좌석의 판별 순액(6,000개, 대칭)에서 30판을 복원 추출한 세션 200,000개마다 최대 누적 손실을 구한다. 올인 규칙(M2)에서 파산 = 누적 손실 ≥ 시작 잔액. 파산 세션 ≤ 5%인 최소 잔액 = 최대 누적 손실의 상위 5% 경계 + 1점.
4. 점당 100 금액으로 바꾸고 1·1.5·2·2.5·3·4·5·6·8 × 10^k 중 그 이상인 가장 작은 값으로 올린다. 다른 점당 금액은 선형 비례.
5. **검증**: 실제로 둔 세션을 엔진 원장(`applySettlement`·`applyInstantPayout`, 올인 상한)으로 정산해 시작 40,000일 때의 파산 수를 몬테카를로 예측과 비교.

```sh
./dev.sh sim --mode session --a commercial --b commercial --rounds 3000 --session-length 30 \
  --per-point 100 --start-balance 40000 --preset standard --seed 11
```

## 4. 파산 확률과 최소 시작 잔액 (표준, 30판 세션)

| 항목 | 값 |
|---|---|
| 세션 최대 누적 손실 | p50 153점 · p90 927점 · **p95 1,415점** · p99 3,177점 |
| 최소 시작 잔액 | 1,416점 = 141,600 (점당 100) → **150,000** (파산 확률 4.5%) |
| 좌석별 추정 (A / B) | 181,400 / 109,700: 같은 AI라 기대값이 같고 차이는 3,000판 표본의 꼬리 잡음 → 두 좌석 합산(대칭) 추정을 채택 |
| 시작 40,000의 파산 확률 | 몬테카를로 26.8% / 실제 세션 원장 31.5% (A 37 + B 26 / 200 잔고 경로) |

몬테카를로와 실제 세션 원장의 파산 비율이 비슷해, 판 사이 상관(나가리 이월, 선)을 무시한 복원 추출이 크게 틀리지 않는다.

**해석**: 시작 잔액의 대부분은 드문 다고(3고 이상: +n점 후 ×2^(n−2)) 판이 정한다. 상용급은 AI-06(기대값)대로 유리한 판에서 고를 여러 번 부르므로 꼬리가 두껍다(판당 p99 544점, 최대 7,680점).

## 5. 참고: 정통 프리셋 (완료된 실행, 기본값에는 미반영)

정통 3,000판(같은 명령, `--preset traditional`)은 중단 전에 끝났다. 보너스 뺏기가 없어 분산이 작다: 판당 평균 27.3점 · 표준편차 70.5 · p95 72 · p99 280 · 최대 2,304점, 3고 이상 6.1%(182판). 세션 최대 누적 손실 p95 650점 → 최소 잔액 65,100 → 올림 **80,000**(파산 확률 3.1%, 좌석별 59,900 / 69,600). 시작 40,000 파산: 몬테카를로 12.7% / 실제 14.5%(15 + 14 / 200). 지시에 따라 기본값은 표준값(150,000)을 준용했다. 재산정 때 정통을 80,000으로 낮출지 결정한다.

## 6. 한계와 후속 (M6 "머니 모델 재산정")

- **미완**: 아케이드 상용급 실행(대박판 ×2 포함)과 휴리스틱 셀프플레이 민감도 실행(프리셋당 30,000판)은 사용자 우선순위 변경으로 중단했다. 아케이드는 대박판 때문에 표준보다 분산이 클 것으로 보여 표준값 준용은 낙관적일 수 있다.
- 표본 3,000판(요구 ≥ 10,000판). p99 이상의 꼬리 표본이 약 30판이라 최소 잔액 추정의 불확실성이 크다(좌석별 추정 110k~181k).
- AI 강도 조정(`docs/ai-tuning.md` 6절)으로 고 성향이 바뀌면 기본값도 바뀐다. 재산정: 2절 명령에 `--rounds 10000 --out 경로`(20코어 기준 프리셋당 약 40분) → 결과 JSON의 `bankruptcy.pooled`·`payoutPoints`를 `money-defaults.ts`의 `MONEY_STATS`로 옮기고 1절 표 갱신(테스트가 대조).
- 밀기는 엔진 미구현(P2)이라 반영되지 않았다. 수수료 없음(M3), 획득 상한은 패자 잔액(M2)만 적용(유한책임제 꺼짐).
