# UI 규범 실기기 확인 절차

대상: `docs/design/ui-spec.md` UX-01~25. 실기기는 사람이 확인하고 실제 결과만 이 문서의 기록 칸에 적는다. 에이전트의 Docker Chromium/WebKit 스냅샷은 실기기 결과를 대신하지 않는다.

## 준비

1. Android 호스트(Galaxy S25 Ultra WebView)와 iPhone Safari를 같은 세션에 연결한다. iPhone의 홈 화면 추가 기능은 사용하지 않는다.
2. 같은 판의 손패 10장·바닥 12월 그룹+뻑 스택이 재현되는 개발 fixture 또는 로그를 준비한다. 실제 판에서 만들 수 없으면 별도 개발 fixture의 실행 경로를 기록한다.
3. iOS 26.5 세로 Safari에서 하단 툴바 표시/숨김별 `window.innerHeight`, `visualViewport.height`, CSS 폭, 안전 영역을 기록한다. **툴바 표시가 평상 플레이 상태**다. 모델별 최소 높이를 확정하기 전까지 문서의 734/822/780px은 임시 가정이다.
4. Safari aA 페이지 확대 100%/200%, Android 시스템 글꼴 크기와 WebView `textZoom`, 동작 줄이기 켬/끔, 밝기와 다크 모드 상태를 기록한다. 테스트 중 효과음·Android 진동 설정을 각각 바꿔 본다.

| iPhone 모델·iOS·세로 | CSS 폭 | 툴바 표시 `innerHeight` / `visualViewport.height` | 툴바 숨김 `innerHeight` / `visualViewport.height` | 최소 높이 판정 |
|---|---|---|---|---|
| 모델 실측 대기 · iOS 26.5 | 실측 대기(360폭 후보) | 실측 대기 | 실측 대기 | 실측 대기 |
| 모델 실측 대기 · iOS 26.5 | 실측 대기(390폭 후보) | 실측 대기 | 실측 대기 | 실측 대기 |
| 모델 실측 대기 · iOS 26.5 | 실측 대기(430폭 후보) | 실측 대기 | 실측 대기 | 실측 대기 |

## 확인 항목

| ID | 조작과 판정 | Android 결과 | iPhone 결과 |
|---|---|---|---|
| D-UX-01 | 툴바 표시의 **실측 최소 `innerHeight`**에서 10장 손패·12그룹 바닥·긴 배너를 본다. 문서 스크롤/잘린 카드/가려진 버튼이 없어야 한다(UX-01~06). | 미실시 | 미실시 |
| D-UX-02 | iPhone Safari **하단 탭 막대 표시** 상태에서 최하단 손패 줄의 `getBoundingClientRect().bottom`과 탭 막대의 화면상 위 경계를 기록하고 겹침 면적 0, 간격 ≥8px인지 잰다. 툴바를 숨겼다 다시 표시한 뒤도 반복하고 Dynamic Island와 상단 HUD 침범 0을 확인한다(UX-02/03). | 해당 없음 | 미실시 |
| D-UX-03 | 고/스톱, 바닥 대상, 국진·흔들기·폭탄·총통을 연다. 모든 선택 버튼과 내 획득패·손패·바닥 후보를 읽고 탭할 수 있어야 한다(UX-08/09). | 미실시 | 미실시 |
| D-UX-04 | 카드 이동 중 빈 바닥으로 스킵하고 같은 손가락을 손패 쪽에서 뗀다. 두 번째 카드가 나가지 않아야 한다(UX-10). | 미실시 | 미실시 |
| D-UX-05 | 연결을 끊고 복귀·호스트 부재·새 기기 교체를 재현한다. 손패는 잠기고 원인·복구 행동이 읽혀야 한다(UX-20/21). | 미실시 | 미실시 |
| D-UX-06 | 소리 끔·효과 강도 끔·시스템 동작 줄이기를 켠다. 사건 문구와 점수는 남고 움직임/플래시는 줄어야 한다. Android 진동만 별도로 확인한다(UX-17~19). | 미실시 | 미실시 |
| D-UX-07 | 화면 읽기·외부 키보드 또는 접근성 탐색으로 바닥 후보와 고/스톱을 선택한다. 제목 초점과 반환 초점을 확인한다(UX-23/24). | 미실시 | 미실시 |
| D-UX-08 | 세로에서 가로로 돌려 안내 덮개와 게임 입력 잠금을 확인하고, 다시 세로로 돌려 선택 상태와 위치를 확인한다(UX-02). | 미실시 | 미실시 |
| D-UX-09 | 기본 **보통**으로 솔로 플레이한다. 낸 카드가 바닥에 닿은 뒤 매칭, 더미 공개, 획득 카드, 뻑·쪽·따닥·쓸·뺏기 문구를 눈으로 따라갈 수 있는지 본다. 곧바로 AI 카드가 움직이지 않고 생각 간격이 보이는지, 재생 중 탭 스킵과 동작 줄이기에서도 막힘이 없는지 확인한다(UX-15~17, AC-06). 빠름·매우 빠름도 전환해 저장값과 체감 순서를 확인한다. | 새 빌드 미실시 | 미실시 |
