# UI 규범 실기기 확인 절차 (결과 미기록)

대상: `docs/design/ui-spec.md` UX-01~25. 실기기는 사람이 확인하고 실제 결과만 이 문서의 기록 칸에 적는다. 에이전트의 Docker Chromium/WebKit 스냅샷은 실기기 결과를 대신하지 않는다.

## 준비

1. Android 호스트(Galaxy S25 Ultra WebView)와 iPhone Safari를 같은 세션에 연결한다. iPhone의 홈 화면 추가 기능은 사용하지 않는다.
2. 같은 판의 손패 10장·바닥 12월 그룹+뻑 스택이 재현되는 개발 fixture 또는 로그를 준비한다. 실제 판에서 만들 수 없으면 별도 개발 fixture의 실행 경로를 기록한다.
3. 화면 확대 100%, 200%, 동작 줄이기 켬/끔, 밝기와 다크 모드 상태를 기록한다. 테스트 중 효과음·Android 진동 설정을 각각 바꿔 본다.
