# 시각 방향 채택 후 기기 확인 절차

관련: VD-01~05, UX-01~25, NF-01~04/07/08, AC-06/07. 이 문서는 **절차만** 정의한다. 이번 디자인 PR에서 실기기 확인은 하지 않았으며 사용자 결과도 아직 없다.

| 항목 | Galaxy S25 Ultra WebView | iPhone Safari (HTTP LAN) | 합격 기준 |
|---|---|---|---|
| 뷰포트 | CSS 412×915/DPR3.5 예상값과 실제 innerHeight·visualViewport 기록 | 주소창 표시/숨김 각각 측정 | 기기명으로 고정값 가정 금지, safe-area 안 입력 |
| 로컬 폰트 | 기본/시스템 글꼴 확대에서 14px 한국어·쉼표·냥·고·배수 확인 | aA 100/125/200%, 재접속 후 확인 | 글리프 누락0·숫자 자리 이동 없음·같은 행동 가능 |
| 동적 이름 | 서브셋 밖 한글/영문/한자를 가진 이름 | 같은 이름 | 시스템 fallback, 이름 때문에 필수 점수/금액 숨김 없음 |
| 판·선택 | 10손패/12월 그룹/뻑, 대상/고스톱 | 툴바 표시 최소높이에서 동일 | 48px 유효 입력, 선택-손패16px, 입력간8px, 가림·문서 스크롤0 |
| 매칭·확정 시인성 (UX-H05·UX-A01) | 기본 힌트에서 황동 3px 단선/청록 4px 이중선, 폭탄·흔들기 보이는 간격, 밝은/어두운 환경 확인 | 누름·키보드 초점 예고와 감소 모션을 같은 공개 판으로 비교 | 도상·48px 입력 가림0, 끔에는 보조 없음·필수 선택 유지. 자동 Chromium/WebKit 샘플은 실기기 판정 아님 |
| 대비·피로 | 밝은 실내/어두운 곳에서 A/B/C 선택안 확인 | True Tone/자동밝기 상태 기록 | 카드 원본 읽기·사건 색+문구 식별, 색만으로 결정하지 않음 |
| 페이싱 | #86 보통/빠름/매우 빠름에서 연속5판 | 가능 시 동일 | 원인→도착→갱신 읽기, 새 효과가 턴에 추가 대기하지 않음 |
| 끄기/스킵 | 빈 바닥 스킵·효과 끔·동작 줄이기 | Reduce Motion과 빈 바닥 스킵 | 카드 추가 내기0, 최종 상태 정확, 정지 효과의 정보 유지 |
| 소리·복귀 | 첫 탭 후 소리, 음소거, 잠금/복귀 | 무음 스위치·첫 제스처·잠금/복귀 | 중복/밀린 음 폭발 없음, 소리 없어도 사건 이해 |
| 완전 오프라인 | 기내모드+로컬 연결, 새 설치 첫 로드 | 셀룰러 끔·새 탭으로 LAN 접속 | 폰트/아이콘/효과가 외부 인터넷 없이 표시 |
| 정산 | 고/배수/밀기/파산/세션종료 | 같은 공개 결과 | 확정 숫자와 잔액 연결, 불가능한 다음 판 버튼 없음 |
