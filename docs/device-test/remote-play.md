# 원격 대전 검증 절차 (승인 전·사람 실행)

관련: spec §13 AC-RP-01~05 · plan RP-03/04/07 · [조사·공식 근거](../research/remote-play.md). **구현 후 사람이 실행할 절차이며 현재 실측 결과 없음.** 자동 E2E는 실기기/Funnel 지원의 증거로 대체하지 않는다.

| 준비 | 확인 |
|---|---|
| 버전 | APK·정적 웹·PC 중계 commit/release·Tailscale 버전, Galaxy/iPhone/Mac OS·WebView/Safari 버전 기록 |
| 망 | Galaxy 셀룰러와 상대 별도 Wi-Fi/셀룰러. 상대 Tailscale 앱/로그인 없이 공개 URL 접속. 집 PC Linux 또는 Windows/WSL2/Docker와 Tailscale 실행 위치 기록 |
| 공개 전 | 강화된 인증 중계만 사용. 기존 relay-dev를 그대로 Funnel에 연결하지 않음. 전용 루프백 포트·MagicDNS·HTTPS 인증서·PC 한정 funnel 속성·기본 제공 ts.net URL 확인 |
| 비용 | 무료 Personal/Free 계정·유료 기능 없음 확인. PC 전원/절전·회선/Windows 업데이트 일정 확인. 토큰·IP 전체·QR 비밀을 결과에 첨부하지 않음 |

| 순서 | 사람이 할 일 | 합격 기준 |
|---|---|---|
| 1 공개 경로 | `tailscale funnel --bg --https=443 <target>`로 전용 중계를 공개하고 status 확인. 같은 PC의 정적 HTTPS 링크 열기 | 인증서 경고 0, 앱/계정/VPN 설치 요구 0, 관리/진단/파일 목록 공개 0 |
| 2 **Funnel WS gate** | Galaxy host·Safari guest로 `/ws?role=...&room=...` 접속. 비밀 없는 서버 측 role/방 일치 판정만 확인 | 양쪽 WS upgrade·query 보존·첫 프레임 인증·relay 알림·hello/snapshot 성공. 실패면 Funnel 지원 미검증/불가, Cloudflare 대안 검토 |
| 3 참여 UX | 링크/QR/코드 각각 새 방에 참여, 로비 이름·설정 확인 | 링크→이름→로비, 코드는 host 수락 후 연결. 이름이 신원 인증이라고 표시되지 않음 |
| 4 공격 경계 | 만료/틀린 토큰·재사용 초대·타 방/역할 토큰·세 번째 탭 시도 | 기존 참가자가 쫓겨나지 않음. 같은 유효 복귀 토큰으로만 4001 교체, 이전 탭 자동 재접속 없음 |
| 5 플레이·지연 | iPhone과 Mac 각각 5판 이상, 2시간 연결 유지(유휴 10분 포함), commit-reveal 결과 확인 | 중복 수/정산 0, 화면 가림 정확. 지연 p50/p95·실패 횟수/총 횟수·망 유형 기록, 국내 지연 보장 수치로 일반화하지 않음 |
| 6 잠금/망 이동 | 양쪽 순서대로 잠금·백그라운드 30초/3분, LTE↔Wi-Fi 변경 | host 부재는 대기·입력 잠금, 복귀 후 상태·원장 일치. 정상 망 복원 후 복귀 소요 기록, 5초 목표 미달도 그대로 기록 |
| 7 PC 장애 | Docker 중계 종료/재시작·PC 절전/복귀·WSL 재시작, 가능하면 Windows 재부팅 | 장애 안내·자동 승패 0. 프로세스 재시작으로 방 메모리 소실 시 새 방 안내, 옛 토큰 재사용 거부. 자동 기동/루프백 가시성 확인 |
| 8 만료·상한 | 검증 환경에서 TTL·동시 방/프레임 제한·quota 실패를 단축 설정해 유발 | 재접속이 만료 연장 안 함, 한도 초과 입력 잠금·안내·유료 전환 0. 실제 무료량을 소진하는 공격 부하 시험은 하지 않음 |
| 9 Mac UI | 가로 창·축소 창·키보드 Tab/Enter·200% 확대 | 모든 필수 선택 가능, 정보 가림/초점 유실 없음. 모바일 세로 회귀 없음 |
| 10 기내 회귀 | 원격 종료 후 인터넷 차단·기내모드에서 LAN/솔로를 새로 시작 | 동일 번들로 첫 실행/대전, 외부 요청 0·Funnel/PC 불필요, LAN gate 기본 닫힘. 세션 자동 이주 없음 |
| 11 대안 DO | 선택된 경우에만 두 망에서 같은 절차와 DO 휴면/배포 재시작 수행 | 재인증·hello/snapshot 복귀, 프레임/게임 로그 영속 저장 없음, Free 한도 실패 시 유료 전환 0 |
