## 준비

1. Android에 해당 APK를 설치하고 기존 맞고 앱이 열려 있으면 종료한다. VPN을 끄고 Wi-Fi를 켠다.
2. iPhone의 모바일 데이터와 VPN은 끈다. 두 기기를 가까이 둔다.
3. Android 앱의 빌드 해시를 적고 `핫스팟 시작`을 누른다. 근처 기기와 알림 권한 안내가 뜨면 허용한다.
4. 핫스팟이 실패하면 앱의 `주소만 표시`를 누르고 두 기기를 같은 Wi-Fi에 연결한다. 이 모드에서는 같은 LAN의 다른 기기에서도 주소에 접근할 수 있으므로 신뢰하는 네트워크에서만 시험한다.

## 한 판 진행

1. Android의 Wi-Fi QR을 iPhone 카메라로 스캔해 접속한다. 인터넷 없음 경고가 나오면 인터넷 없이 사용을 선택한다. SSID가 화면과 같은지 확인한다.
2. Android의 게임 URL QR을 스캔한다. iPhone Safari에서 로비가 보이는지 확인하고, Android WebView에도 로비가 보이는지 확인한다. QR 로드가 실패하면 Android 진단 화면의 IP, 서버 상태, `/health`, `/smoke`를 기록한다.
3. 각자 이름을 입력한다. 호스트/게스트 이름과 접속 상태, 규칙 프리셋, 점당 금액, 시작 잔액이 양쪽에 같은지 확인한다. 게스트 준비를 켜고 호스트가 시작한다.
4. 카드 선택부터 고/스톱 또는 판 종료까지 한 판을 진행한다. 양쪽 점수와 정산 금액을 적는다. 추가 게스트 기기가 있으면 같은 URL을 열어 두 번째 게스트가 거절되는지 확인한다.
5. 게스트 iPhone 화면을 잠갔다가 10초 뒤 해제한다. 연결과 판 상태가 5초 안에 복구되는지 확인한다. 1분 잠금도 반복한다.
6. Android에서 홈으로 이동해 1분 대기한다. 알림이 하나만 남는지 보고 앱으로 돌아온다. 게임과 핫스팟 상태를 확인한다. 진행 중 화면 꺼짐 방지도 확인한다.
7. Android의 진단 화면을 열어 호스트/게스트 로그, 역할별 접속 수, 빌드 정보를 확인하고 `로그 공유`로 파일을 내보낸다. 비밀번호가 공유 로그에 평문으로 나오지 않는지도 확인한다.
