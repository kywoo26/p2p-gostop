## 설치와 연결

1. 전달받은 M4 APK를 Android에 설치한다. 개발 빌드는 `./dev.sh build:web` 다음 `./dev.sh apk:debug`로 만들며, 파일은 `android/app/build/outputs/apk/debug/app-debug.apk`에 있다. APK의 출처와 앱에 보이는 빌드 해시를 위에 적는다.
2. 두 기기의 VPN을 끈다. Android에서 Wi-Fi를 켜고 앱을 연다. 앱에서 **호스트 방**을 연 뒤 **핫스팟 시작**을 누른다. 주변 기기 권한 안내가 나오면 허용한다. 알림 권한 안내는 화면의 설명을 확인하고 선택한다.
3. 호스트 방에 Wi-Fi 이름과 비밀번호, 두 QR이 나타나는지 본다. iPhone 카메라로 **Wi-Fi QR**을 찍어 연결한다. “인터넷 없음” 안내가 나오면 인터넷 없이 사용을 선택한다. 이어 **게임 주소 QR**을 찍어 Safari에서 연다.
4. 핫스팟을 켤 수 없으면 Android의 시스템 핫스팟을 직접 켜거나 두 기기를 같은 Wi-Fi에 연결한 뒤, 호스트 방의 **주소만 표시**를 사용한다. 이때 같은 Wi-Fi의 다른 기기도 게임 주소에 닿을 수 있으므로 신뢰하는 네트워크에서만 시험한다.
5. Safari와 Android에 로비가 보이는지 확인한다. QR이 열리지 않으면 Android의 **진단**에서 IP와 서버 상태를 적고, iPhone Safari에서 `http://<화면에 보이는 IP>:17777/health`와 `http://<화면에 보이는 IP>:17777/smoke`를 차례로 열어 결과를 적는다.

## 한 판과 복귀

1. 양쪽 로비에서 이름, 접속 상태, 규칙, 점당 금액과 시작 잔액을 확인한다. 게스트가 준비를 누른 뒤 호스트가 시작한다.
2. 카드 선택부터 고/스톱 또는 판 종료까지 한 판을 진행한다. 양쪽 카드·점수·정산 금액이 같은지 적는다.
3. iPhone 화면을 10초 잠갔다가 풀고 게임으로 돌아온다. 이전 판이 다시 나타나는지, 접속 표시가 5초 안에 돌아오는지 확인한다. 1분 잠금도 반복한다.
4. Android 전원 버튼으로 화면을 1분 끈 뒤 켠다. 게임판이 유지되는지 확인한다. 이어 홈 화면으로 나가 1분 기다린다. 핫스팟 알림이 하나인지 확인하고 **알림을 눌러** 돌아온다. 새 게임 화면이 중복으로 열리지 않고 같은 판이 보이는지 확인한다.
5. Android를 회전하고, 가능하면 화면 모드(밝게/어둡게)를 바꾼다. 판이 초기화되지 않는지 확인한다. 진행 중 뒤로 가기를 눌러 종료 확인창이 나오는지도 확인하고 **계속하기**를 고른다.
6. 게임에서 **진단**을 열어 서버·호스트/게스트 연결·빌드 정보를 확인한 뒤 뒤로 가기로 같은 게임에 돌아온다. **로그 공유**를 눌러 요약 글과 첨부 파일이 모두 전달되는지 확인한다. 공유 내용에 Wi-Fi 비밀번호가 평문으로 들어가지 않는지 본다.
