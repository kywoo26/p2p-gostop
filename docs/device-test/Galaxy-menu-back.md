# Galaxy 메뉴·Back·솔로 저장 확인 절차 (v0.2.1-B)

사람 검증용 절차다. 기기에서 수행한 결과는 검증자가 별도로 기록한다.

1. Galaxy에 웹 번들이 포함된 APK를 새로 설치한다. 홈 → 혼자 연습 → 시작으로 판을 연다. 메뉴 버튼이 상태 표시줄·카메라 컷아웃을 가리지 않고 48dp 이상인지 확인한다.
2. 카드 선택(고/스톱·흔들기 등)이 뜨면 시스템 Back을 누른다. 선택이 취소되지 않고 게임 메뉴가 열리는지 확인한다. 메뉴가 열린 동안 판을 탭해도 카드가 나가지 않아야 한다.
3. 메뉴에서 시스템 Back을 누른다. 메뉴가 닫히고 원래 메뉴 버튼에 초점이 돌아오는지 확인한다. 다시 메뉴 → 설정 → 시스템 Back으로 같은 판에 복귀한다.
4. 메뉴 → 홈 → 이어하기로 돌아온다. 판 번호·잔액·시드가 유지되는지 확인한다. 홈에서 시스템 Back을 누르면 기존 네이티브 앱 종료 확인이 떠야 한다.
5. 혼자 연습에서 새 게임을 누른 뒤 취소한다. 판·잔액·기록이 그대로인지 확인한다. 세션 종료를 두 번 확인하고 종료 화면의 최종 잔액과 기록을 확인한다. “다음 판” 버튼이 없어야 한다.
6. 저장소 오류 또는 손상된 저장 데이터가 있는 시험 빌드에서는 안내가 보이고 자동으로 새 세션이 시작되지 않는지 확인한다. 브리지가 준비되기 전에 Back을 누르면 기존 네이티브 종료 확인이 유지되는지 확인한다.
