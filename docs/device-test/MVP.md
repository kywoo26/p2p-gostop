# MVP 실기기 테스트 — 맞고 P2P v0.1.0-alpha

이 문서는 개발자가 아니어도 따라 할 수 있도록 순서대로 정리했습니다. 어렵게 느껴지는 부분은 없으니 위에서부터 그대로 따라 하면 됩니다.

- 대상 빌드: GitHub Releases의 `v0.1.0-alpha`
- 호스트(게임을 여는 쪽): 삼성 Galaxy S25 Ultra (Android 16)
- 게스트(참여하는 쪽): iPhone (iOS 26.5, Safari 브라우저)
- 검증자/날짜: `_______` / `_______`

## 0. 설치 (처음 한 번, 또는 업데이트)

1. Galaxy에서 `https://github.com/kywoo26/p2p-gostop/releases` 를 엽니다. 비공개 저장소라 GitHub 로그인이 필요합니다. 로그인 화면이 뜨면 계정으로 로그인합니다.
2. `v0.1.0-alpha` 항목의 **Assets**를 펼쳐서 `.apk` 파일을 다운로드합니다.
3. 다운로드 알림이나 "내 파일 → 다운로드"에서 APK를 눌러 엽니다.
4. 이미 이전 버전 맞고 P2P 앱이 설치되어 있어도 그대로 진행합니다. 같은 서명 키로 만든 앱이라 **덮어쓰기 설치**가 됩니다(삭제할 필요 없음).
5. "출처를 알 수 없는 앱" 경고가 뜨면 **설정 → 이 출처 허용**을 켜고 다시 **설치**를 누릅니다.
6. Play 프로텍트 경고가 뜨면 **세부정보 더보기 → 무시하고 설치**를 누릅니다.

## 1. 호스트(Galaxy)에서 판 열기

1. **맞고 P2P** 앱을 엽니다. 게임 화면이 아니라 앱 자체의 첫 화면(네이티브 화면)이 보입니다.
2. **핫스팟 시작**을 누릅니다. 비행기 모드는 켜져 있어도 되고, 그 상태에서 Wi-Fi만 다시 켜도 괜찮습니다.
3. 화면에 Wi-Fi 이름(SSID)과 비밀번호, 이 폰의 IP 주소, 그리고 QR 코드 두 개(① Wi-Fi 연결용, ② 게임 주소용)가 나타납니다.
4. 잠시 후 게임 화면으로 자동으로 넘어갑니다. **QR 코드를 다시 봐야 하면** 뒤로 가기를 누르거나, 상단 알림(맞고 P2P 핫스팟 실행 중)을 눌러 원래 화면으로 돌아가면 QR이 다시 보입니다.

## 2. 게스트(iPhone)에서 참여하기

1. 기본 **카메라** 앱으로 Galaxy 화면의 **① Wi-Fi QR**을 비춥니다. 뜨는 배너를 눌러 연결합니다.
2. "인터넷 연결 없음"이라는 안내 창이 뜨면 반드시 **"인터넷 없이 사용"**을 선택합니다("취소"를 누르면 연결이 끊깁니다). 안내 창이 안 떠도 정상입니다.
3. 다시 카메라로 **② 게임 주소 QR**을 비춥니다. 배너를 누르면 Safari가 열리며 `http://<Galaxy의 IP>:17777/` 주소로 이동하고, 자동으로 게스트용 게임 화면으로 넘어갑니다.

## 3. 게임 진행

1. 두 화면(Galaxy, iPhone) 모두 **"선 정하기"** 화면이 먼저 나옵니다. 각자 카드를 한 장 고릅니다.
2. 이후 본 게임: 내 손에서 **밝게 표시된(하이라이트) 카드**를 눌러 냅니다. 바닥에 같은 달(월) 카드가 두 장 있으면 **노란 테두리로 표시된 바닥 카드**를 눌러 짝을 맞춥니다.
3. 조건이 맞으면 화면에 안내 버튼이 뜹니다: **고/스톱**(선택 시 각각 받을 돈 예상액도 함께 보임), **흔들기**, **총통**, **국진**, **폭탄**. 뜬 버튼 중 원하는 것을 누르면 됩니다.
4. 한 판이 끝나면 아무 쪽이나 **"다음 판"**을 눌러 이어서 진행합니다.

## 4. 화면 잠금 테스트

iPhone 화면이 잠기면 그냥 다시 잠금을 풀면 됩니다. 보통 몇 초 안에 자동으로 다시 연결됩니다. 만약 화면에 **"끊김"** 표시가 계속 남아 있으면 Safari 페이지를 새로고침합니다.

## 5. 이번 버전에서 아직 없는 기능 (정상입니다, 오류 아님)

- 카드 움직이는 애니메이션, 효과음, 설정 화면 없음
- 규칙은 표준(기본) 규칙만 있음, 점당 100냥, 시작 잔액 150,000냥
- 호스트(Galaxy) 쪽 앱을 완전히 끄면 게임이 종료됩니다(끄지 마세요)
- 손님(게스트)은 한 명만 접속 가능합니다. 두 번째 게스트가 접속을 시도하면 거절됩니다

## 문제 해결

- **QR을 스캔해도 안 열릴 때**: Safari 주소창에 화면에 표시된 주소를 `http://192.168.x.x:17777/` 형태로 직접 입력합니다.
- **화면이 하얗게(빈 화면) 나올 때**: Safari를 새로고침합니다.
- **"상대 없음"이라고 나올 때**: iPhone 설정 → Wi-Fi에서 `AndroidShare_…`로 시작하는 네트워크에 연결되어 있는지 확인합니다. 아니면 QR ①을 다시 스캔합니다.
