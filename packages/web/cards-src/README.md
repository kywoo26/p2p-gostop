# 자체 제작 카드 원본 (CC0 1.0)

보너스 카드 3장과 카드 뒷면의 사람이 읽는 원본이다. `scripts/build-cards.mjs`가 svgo로 최적화해
`public/cards/{48,49,50,back}.svg`로 내보낸다(Commons 원본 캐시 없이 이 4장만 다시 만들 때는 `--originals-only`).
이 디렉터리의 파일과 그 산출물은 p2p-gostop 기여자가 직접 그린 것이며
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)으로 공개한다(spec 6.6·NF-07, plan.md D1).

## 화풍 (Commons "SVG Hwatu" 세트에 맞춤)

- 판형·테두리: 좌표계 `103.2 × 168.2`, 바깥 주홍 테(`#ef1d1e`, 반경 5), 흰 앞면 안쪽 반경 7, 안쪽 먹선 1.2.
  나란히 놓았을 때 크기·테두리가 Commons 카드와 같다.
- 팔레트: 흰 바탕, 먹 `#000`, 주홍 `#ef1d1e`, 노랑 `#faea01`, 파랑 `#1ca4da`(Commons와 같은 값). 뒷면만 짙은 주홍
  `#a8111a`와 금 `#f2c230`을 더한다.
- 평면 도형과 굵은 먹 윤곽만 쓴다. `<text>`·filter·gradient·래스터·외부 주소 없음. 글자는 선(path)으로 그린다
  (`<img>` 안의 SVG는 시스템 글꼴에 따라 달라지기 때문). svgo 후 1장 8 KB 이하(빌드 스크립트가 검사).
- Commons 그림의 경로를 복사·트레이싱하지 않았다. 참조는 판형·색과 "먹 언덕·물결·붉은 땅" 같은 통상적인 구성뿐이다.

## 파일

| 파일              | 카드          | 그림                                                                                        |
| ----------------- | ------------- | ------------------------------------------------------------------------------------------- |
| `bonus-2pi-a.svg` | 48 보너스 2피 | 위 "보너스", 가운데 주홍 숫자 + 먹 "피", 아래 먹 언덕                                       |
| `bonus-2pi-b.svg` | 49 보너스 2피 | 같은 구성, 아래 푸른 물결                                                                   |
| `bonus-3pi.svg`   | 50 보너스 3피 | 같은 구성, 아래 주홍 땅(11월·12월 쌍피처럼 붉은 면 = 값이 큰 피)                            |
| `back.svg`        | 뒷면          | 짙은 주홍 바탕에 잔잔한 마름모 격자, 한지색 외곽·금색 이중 테·모서리 꺾쇠, 가운데 매화 원문 |

보너스 3장의 "뺏기" 표식: 노란 갈고리가 "피"라고 쓴 작은 카드를 걸어 온다(발동 조건은 rules-commercial.md §12 B3, 뺏기 토글은 엔진이 결정한다).
얼굴처럼 보일 수 있는 원·점 배치는 쓰지 않는다.
